雲端設定／登入

首次設定：① 填入 Supabase 專案網址與 Publishable key（不可使用 Secret／service_role）。② 將下方 SQL 貼到 SQL Editor 執行。③ 在 Authentication → Users 建立並確認使用者信箱。④ 使用該帳號登入。所有裝置請使用同一專案及同一帳號。

填完後請將此網頁放到原本網站，以 HTTPS 開啟。設定會記在此瀏覽器；也可在 HTML 的 supabaseUrl、supabaseKey 預先填入公開設定。

登入後自動儲存排班、人員、銷量與庫存，每 15 秒讀取其他裝置的更新。同一區塊若被其他裝置先修改，會停止覆蓋並提示；請先備份再重新讀取。斷線時變更會保留為待同步資料。雲端設定後未登入或讀取未完成時暫停編輯。
